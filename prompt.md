# Prompt — Ecommerce de Energía, Respaldo y Soluciones Solares

Quiero diseñar y desarrollar un ecommerce moderno, rápido y orientado a
conversión para un negocio especializado en productos de energía, respaldo
eléctrico, energía solar, iluminación eficiente y accesorios.

## 1. Objetivo del proyecto

El ecommerce debe funcionar como una extensión de una estrategia comercial
basada principalmente en redes sociales.

El flujo principal del negocio es:

**Facebook / Instagram → Ecommerce → WhatsApp → Venta**

El usuario normalmente descubrirá un producto mediante una publicación en redes
sociales y llegará al ecommerce para:

- conocer el producto;
- entender para qué sirve;
- verificar características;
- consultar disponibilidad;
- conocer el precio;
- contactar por WhatsApp para completar la compra.

No quiero un ecommerce tradicional enfocado en procesos complejos de registro,
cuentas de usuario o checkout pesado.

La prioridad es:

**velocidad + claridad + confianza + conversión + WhatsApp**

---

# 2. Público objetivo

El ecommerce está dirigido principalmente a:

- hogares;
- pequeños negocios;
- personas que necesitan respaldo eléctrico;
- personas interesadas en energía solar;
- personas que buscan iluminación eficiente;
- usuarios que necesitan soluciones para cortes eléctricos;
- compradores que no necesariamente tienen conocimientos técnicos.

Por ello, la interfaz debe explicar los productos de forma sencilla y comercial.

No asumir que el usuario sabe qué significa MPPT, Wh, Ah, W, LiFePO4, etc.

Cuando aparezcan términos técnicos, acompañarlos con explicaciones simples.

---

# 3. Posicionamiento

No presentar la marca únicamente como una tienda de "energías limpias".

El concepto comercial debe girar alrededor de:

**energía + autonomía + respaldo + ahorro + soluciones para el hogar**

La propuesta de valor debe transmitir:

- seguridad;
- disponibilidad;
- autonomía;
- soluciones prácticas;
- asesoría;
- productos confiables.

La sensación general debe ser:

**"Aquí encuentro una solución para mi problema energético."**

No simplemente:

**"Aquí venden productos eléctricos."**

---

# 5. Categorías principales

Mostrar cuatro categorías visuales:

### ☀️ Energía Solar

Paneles, controladores, inversores y kits solares.

### 🔋 Respaldo y Almacenamiento

Power stations, baterías, UPS, inversores y soluciones de respaldo.

### 💡 Iluminación

Lámparas solares, iluminación LED, reflectores y luces de emergencia.

### ⚡ Accesorios

Cables, conectores, adaptadores, soportes, fusibles y otros accesorios.

Las categorías deben poder abrirse directamente desde la Home.

# 13. CTA de WhatsApp

WhatsApp debe ser el CTA comercial principal.

Cada producto debe tener:

**"Consultar por WhatsApp"**

Al pulsar, generar un mensaje contextualizado:

"Hola, estoy interesado en [PRODUCTO]. ¿Está disponible?"

No obligar al usuario a copiar manualmente el nombre del producto.

También crear un botón flotante de WhatsApp.

Debe ser visible pero no invasivo.

# 18. Mobile First

Esta parte es extremadamente importante.

El ecommerce será utilizado principalmente desde teléfonos móviles provenientes
de Facebook, Instagram y WhatsApp.

Diseñar primero para:

### 360px

### 390px

### 430px

Después adaptar a tablet y desktop.

La experiencia móvil debe ser excelente.

Los elementos táctiles deben tener suficiente tamaño.

No utilizar interfaces excesivamente densas.

---

# 19. Rendimiento

El público objetivo puede tener conexiones extremadamente lentas, incluso
inferiores a 1 Mbps.

Por lo tanto, el rendimiento es una prioridad absoluta.

La implementación debe estar optimizada para:

- Astro;
- generación estática cuando sea posible;
- mínimo JavaScript;
- imágenes WebP/AVIF;
- imágenes responsive;
- lazy loading;
- compresión;
- fuentes optimizadas;
- evitar librerías innecesarias;
- evitar sliders pesados;
- evitar videos de fondo;
- evitar animaciones costosas.

La página principal debe comenzar a mostrar contenido útil inmediatamente.

No depender de JavaScript para mostrar el contenido principal.

---

**moderno + tecnológico + confiable + limpio + comercial**

Evitar un aspecto excesivamente corporativo.

Evitar parecer una empresa industrial gigante.

Utilizar:

- mucho espacio en blanco;

- tipografía moderna;
- iconografía simple;
- fotografías de productos de alta calidad;
- llamadas a la acción claras;
